# Licensing decision

## Current status

The repository is currently private and no open-source license is granted. Copyright and all usage rights remain with the repository owner unless a separate written agreement applies.

This is an intentional provisional decision while the product architecture, clinical claims, data-protection model, third-party dependencies and intended operating model are still being defined.

## Consequences

- Repository access does not grant permission to redistribute, sublicense or commercially exploit the software.
- Contributions require an explicit agreement before code from external contributors is accepted.
- Dependency licenses must remain compatible with a possible later commercial or open-source distribution.
- No release may be described as open source until a recognized license file has been added deliberately.

## Decision gate before the first external release

Before any external pilot or public release, choose and document one of these models:

1. proprietary commercial licensing;
2. source-available licensing with defined operational restrictions;
3. an OSI-approved open-source license;
4. dual licensing for community and commercial operation.

The decision must include a dependency-license review, ownership of contributions, trademark handling, warranty and liability language, and the impact of medical or diagnostic use claims.
