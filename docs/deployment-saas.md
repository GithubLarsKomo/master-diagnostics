# SaaS-Modus

Zielkonfiguration:

- `DEPLOYMENT_MODE=saas`
- Clerk als Identity Provider
- Turso Cloud als Datenbank
- Plattform-Admin-Oberfläche
- mehrere logisch getrennte Tenants

Die konkrete Cloud-Plattform bleibt austauschbar; keine proprietären Serverless-Funktionen dürfen fachlich erforderlich sein.
