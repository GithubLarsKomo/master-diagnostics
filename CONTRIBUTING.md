# Beitragen

1. Änderung einem Task oder Issue zuordnen.
2. Fachregeln zuerst als Tests formulieren.
3. Keine Datenbankmutation ohne Tenant-Autorisierung und Audit-Prüfung.
4. Algorithmusänderungen benötigen eine neue Version und Referenztests.
5. Keine Secrets oder personenbezogenen Testdaten committen.
6. Pull Request mit nachvollziehbaren Akzeptanzkriterien eröffnen.
