# Masters Diagnostics brand assets

The master mark combines three product properties: Masters identity (the M), diagnostic measurement (the plotted curve) and performance progression (the rising endpoint). The mark uses only canonical `sport-performance` colors from `DESIGN.md`.

Assets:
- `masters-diagnostics-mark.svg` — canonical vector mark
- `masters-diagnostics-logo.svg` — full lockup with product descriptor
- `favicon-32.png` — browser favicon
- `apple-touch-icon.png` — iOS home-screen icon
- `app-icon-192.png` / `app-icon-512.png` — PWA icons

Do not recolor or substitute framework/default icons.
